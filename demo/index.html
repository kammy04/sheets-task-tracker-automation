Sheets Task Tracker: live demo

This page runs the tracker's real logic (src/Core.js, the same file the Apps Script uses) in your browser. Import the sample CSVs in order, or upload your own, and watch the Tasks sheet, the audit log and the weekly summary update. In Google Sheets this happens automatically when a CSV lands in the Drive inbox folder. Source on GitHub
